# 💫 About Me:
Hello, I am a recent Software Engineering graduate from Addis Ababa Science and Technology University, with a strong focus on frontend development and data engineering.<br><br>Alongside my academic studies, I was part of the A2SV (Africa to Silicon Valley) program—an initiative that supports African students in advancing their programming and software development skills. Through this program, I strengthened my knowledge of data structures and algorithms and completed my first internship as a web developer.<br><br>I have experience building both web and mobile applications using React and React Native. Additionally, I’ve worked on data pipeline automation projects that involve transforming raw data into meaningful insights using tools like Google Cloud Platform (GCP).<br><br>I'm also familiar with AI development, particularly in no-code environments, building AI agents using CREW AI, and integrating AI into web and mobile applications to enhance user experience and meet business needs.<br><br>Currently, I am working on machine learning projects and am open to collaborations in this area.
